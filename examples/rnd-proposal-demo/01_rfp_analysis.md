# RFP 분석: 중소기업 대상 생성형 AI 도입 지원 플랫폼 개발

> 데모용 합성 공고 분석 (비민감·가상). 축약본.

## 0. 과제 개요
- 사업명: 중소기업 대상 생성형 AI 도입 지원 플랫폼 개발
- 공고기관: (데모, 미지정)
- 과제유형: **기술개발형** (판정 근거: 플랫폼 "개발" 산출물 + 사업화가능성 30점 고배점 → TRL·성능·사업화 요구 구조)
- 연구기간: 2년 (2026~2027)
- 총 사업비: 3억원 / 매칭펀드: 공고 미명시(§7)
- 신청마감: 공고 미명시(§7)

## 2. 평가지표 및 배점
| 평가항목 | 배점 | 세부 기준(추정) |
|----------|------|-----------------|
| 필요성 | 20 | 문제 심각성·수요 근거의 실증성 |
| 기술개발성 | **30** | 기술 완성도·차별성·구현 가능성 |
| 사업화가능성 | **30** | 시장성·BM·확산(보급) 전략 |
| 추진체계 | 20 | 추진 로드맵·수행역량·리스크(보안) 관리 |
| **합계** | **100** | — |

- **가중 우선순위: 기술개발성(30) = 사업화가능성(30) > 필요성(20) = 추진체계(20)**
- 고배점 60점(기술+사업화)에 지면·근거를 집중 배분해야 함.

## 3. 양식·분량·자격 제약
- 지정 양식: **없음** → 표준 R&D 제안서 구조 자체 생성
- 페이지 한도·글꼴·여백·자격·매칭비율·제출서류: 공고 미명시(§7)

## 4. 핵심 키워드
생성형 AI, 중소기업, 도입 지원, 플랫폼, 실태(도입률), 차별성, 단계별 로드맵, 개인정보·보안, 사업화

## 7. 사용자 확인 필요 사항
- 매칭펀드 비율, 페이지 한도, 신청 자격, 제출서류 목록: 공고 미명시 → 실제 공고 확인 필요
- R4(개인정보·보안)의 배점 귀속: 명시 배점표에 독립 항목 없음 → 추진체계(20)에 흡수 가정
