# 런타임 노트 — 실행 환경별 안내

## 1. 실행 방식 — 순차 스폰이 기본, 팀 API는 선택

오케스트레이터 스킬의 본문은 **리더(메인 세션)가 `Agent` 도구로 에이전트를 단계 순서대로 스폰하고 전달을 중계하는 방식**으로 적혀 있다. 특별한 기능을 켤 필요가 없고, 처음부터 끝까지 완주가 확인된 경로다. Phase 순서와 산출물 파일 계약(`_workspace/01…06`)이 전부다.

에이전트 팀 API(`TeamCreate`/`TaskCreate`/팀 `SendMessage` — 실험 기능)가 켜진 환경이면 같은 파이프라인을 팀으로 돌릴 수도 있다(스킬 말미 "팀 API를 쓸 때"). 이 경로는 완주 검증 기록이 없으니 처음 쓴다면 작은 공고로 먼저 돌려 본다.

**파일 쓰기 확인**: 실행 환경이나 권한 설정에 따라 서브에이전트의 파일 쓰기가 거부되는 경우가 있다. 리더는 각 단계 뒤 산출물 파일이 실제로 생겼는지 확인하고, 거부되면 그 단계만 전경 호출로 다시 스폰하거나 에이전트가 돌려준 내용을 직접 파일로 쓴다. 항상 생기는 일은 아니므로 전 단계를 미리 전경 직렬로 묶을 필요는 없다.

## 2. 모델 선택 — 단계별 티어와 성능 폴백

공개판 기본값은 **단계별 모델 티어**다: 득점 단계(rfp-analyst·proposal-writer·proposal-reviewer)는 `model: inherit`(세션 모델 상속), 조사(research-investigator)는 `sonnet`, 변환(hwpx-exporter)은 `haiku`. 세션을 opus로 돌려도 검색·수집과 기계적 변환이 무거운 모델을 기다리지 않게 한 배치다.

- **품질 우선**: 난도 높은 기술분야 공고처럼 품질이 우선이면 스폰 시 opus급 지정(업시프트)을 권장. 근거 판별이 까다로운 주제는 조사도 상위 지정.
- **속도 우선**: "빨리"라고 요청하거나 제출 마감이 임박하면 오케스트레이터가 쾌속 프로파일(조사 분할 병렬·집필 섹션 배치 분할·수정 루프 1회)로 전환한다. 안내 예산(합계 180분)은 **이 킷에서 잰 값이 아닌 잠정치**라 첫 실행의 `_workspace/_run_log.md`로 자기 환경 값을 확인해 고쳐 쓰는 것을 권한다. 어느 단계가 안내 예산을 크게 넘으면 지연 폴백 래더가 남은 단계를 순서대로 경량화한다(분할·병렬화 → 다운시프트 → 루프 축소 → 사용자 범위 협상). 상세: 오케스트레이터 스킬의 "실행 프로파일 — 표준 vs 쾌속" 절.
- **실패 시 업시프트**: 변환 결과는 리더가 검증기(`skills/rnd-hwpx-export/scripts/verify_hwpx.py`, python3 표준 라이브러리만)로 직접 대조한다. 종료 코드가 1이면 한 단계 위 모델로 1회 재스폰한다. 발주처 지정 양식을 채우는 변환은 처음부터 `sonnet`으로 스폰한다. 검증 게이트(reviewer)는 어떤 프로파일에서도 모델을 낮추지 않는다.

## 3. 한글(.hwpx) 경로 — kordoc

```
claude mcp add kordoc -- npx -y kordoc@latest mcp
```

- 지정 양식이 있으면 폼 채우기(`parse_form`→`fill_form`), 없으면 `generate_document` 표준 생성.
- kordoc 미설치·장애 시: 마크다운/docx 산출까지 진행하고 변환만 보류한다. MCP 게이트 장애 시 `npx -y kordoc@latest` 직접 구동 우회도 스킬에 문서화돼 있다.
- **기존 .hwp를 입력으로 줄 때의 한계**: .hwp→마크다운 추출은 표·그림을 평탄화한다. 기존 보고서의 검수·보완 작업은 "원본 수정 가이드" 산출 방식을 권장한다(추출본 재생성으로 원본을 대체하지 않는다).
- 독점 기관 양식은 이 저장소에 포함되지 않는다(BYO-template). 자기 기관 양식은 런타임에 `_workspace/00_input/`으로 제공하라.

## 4. 해외 조사 현지화 — geo-search (선택)

조사 스킬 `rnd-research`에는 SERP API 래퍼(`scripts/geo_search.py`)가 내장돼 있다. 기본 WebSearch가 US 로케일 고정인 한계를 보완해 "일본 사례는 일본어로, 독일 통계는 독일어로" 검색한다.

- 키 설정(둘 중 하나): `SERPER_API_KEY`(serper.dev, 권장) 또는 `SERPAPI_KEY`(serpapi.com, 무료 100/월). 환경변수 또는 키 파일(`~/.serper/key` / `~/.serpapi/key`). 두 서비스의 키는 호환되지 않는다.
- 키가 없으면 스킬이 자동으로 WebSearch 폴백을 쓴다 — 필수 아님.

## 5. 산출물 워크스페이스

이 킷은 작업 디렉토리에 `_workspace/`를 만들어 단계 산출물(설계→게이트 판정→근거→초안→검수→최종)을 파일로 남긴다. 재실행·부분 수정("3장만 다시", "hwpx만 재생성")은 이 파일들을 기준으로 동작하므로 **`_workspace/`를 지우지 말 것**. 저장소에 커밋하지 않도록 `.gitignore`에 포함돼 있다.

## 6. 외부 의존성 — 무엇이 필수이고, 없으면 어떻게 되나

이 킷이 스킬·에이전트 문서에서 이름으로 부르는 외부 자산 전부다. 여기 없는 것은 킷 안에 들어 있다.
